## 🎯 프로젝트 소개

이 프로젝트는 **대한민국 공공기관에서 사용하는 문서 작성**을 위한 전문 AI 프롬프트 템플릿을 제공합니다. 

### 📁 포함된 템플릿
- **국민신문고 민원답변서** 작성용 프롬프트
- **정부기관 공문서** 작성용 프롬프트
- 각각 **사람용**(가독성 중심)과 **AI용**(효율성 중심) 버전 제공

---

## 🧠 프롬프트 엔지니어링이란?

**프롬프트 엔지니어링(Prompt Engineering)**은 AI가 원하는 결과를 정확하게 생성하도록 **명령어를 체계적으로 설계하는 기술**입니다.

### 간단한 예시 비교

#### ❌ 일반적인 요청
```
"민원 답변서 써줘"
```

#### ✅ 프롬프트 엔지니어링 적용
```
당신은 대한민국 공공기관의 민원담당 공무원입니다.
다음 단계를 따라 민원답변서를 작성하세요:
1. 문서 유형 판단 (공개용/비공개용)
2. 해당 템플릿 선택
3. Context 기반 답변 생성
4. 검증 체크리스트 확인
```

## 💡 왜 프롬프트 엔지니어링이 필요한가?

### 🎯 **정확성 향상**
- **일반 요청**: 형식이 일정하지 않고 누락되는 내용 발생
- **프롬프트 엔지니어링**: 체계적인 구조로 일관된 품질 보장

### ⚡ **효율성 증대**
- **수작업**: 문서 1개 작성에 30-60분 소요
- **AI + 프롬프트**: 문서 1개 작성에 2-5분 소요 (약 **10-15배 빠름**)

### 🔄 **표준화 달성**
- 모든 문서가 동일한 형식과 품질 기준을 유지
- 담당자가 바뀌어도 일관된 문서 작성 가능

### 🛡️ **오류 방지**
- 필수 항목 누락 방지
- 개인정보 보호 규정 자동 준수
- 문서 형식 오류 최소화

## 🚀 사용법

### 1단계: 적절한 템플릿 선택
```
목적에 따른 선택:
├── 학습/이해: 사람용 버전 참조
└── 실제 사용: AI용 버전 사용
```

### 2단계: AI 도구에 프롬프트 입력
1. ChatGPT, Claude, Bard 등 AI 도구 접속
2. AI용 프롬프트 전체 내용 복사 후 붙여넣기
3. "Context:" 뒤에 작성하고자 하는 내용 입력

### 3단계: 결과 확인 및 수정
```
AI 출력 → 내용 검토 → 필요시 수정 요청 → 최종 완성
```

### 📝 사용 예시

#### 국민신문고 민원답변 작성
```
[AI용 프롬프트 전체 내용]

Context: 
- 민원 내용: 어린이집 확충 요청
- 민원인: 김○○ (개인정보 포함)
- 담당자: 홍길동 (02-1234-5678)
```

#### 공문서 작성
```
[AI용 프롬프트 전체 내용]

Context:
- 주제: 2024년 하반기 예산 집행 계획 안내
- 수신: 각 부서장
- 담당자: 재무팀 이○○ (02-9876-5432)
```

## 🎨 설계 원칙

### 📐 **구조적 명확성**
- **계층적 정보 구조**: 헤더-섹션-항목 순서로 체계화
- **단계별 프로세스**: 분석 → 판단 → 생성 → 검증 순서
- **템플릿 표준화**: 일관된 형식으로 예측 가능한 결과

### 🎯 **명령어 최적화**
- **강조 키워드**: `MUST`, `ALWAYS`, `NEVER` 등으로 중요도 표시
- **조건부 로직**: `IF-THEN` 구조로 상황별 대응
- **하이브리드 언어**: 구조는 영어, 내용은 한글로 최적화

### 🛡️ **품질 보증 체계**
- **사전 검증**: 문서 유형 판단, 필수 정보 확인
- **실시간 가이드**: 각 단계별 상세 지침 제공
- **사후 체크**: 완성 후 검증 체크리스트 적용

### 🔄 **사용자 친화성**
- **이중 버전**: 학습용(사람)과 실행용(AI) 분리
- **명확한 지시**: 애매한 표현 배제, 구체적 명령어 사용
- **오류 방지**: 흔한 실수를 예방하는 안전장치 내장

## 💡 효과적인 활용 팁

### ✨ **Context 작성 요령**
1. **구체적으로**: "예산 관련" → "2024년 3분기 예산 집행률 향상 방안"
2. **필수 정보 포함**: 담당자 정보, 날짜, 핵심 내용
3. **개인정보 주의**: 민원답변 시 개인정보 포함 여부 명시

### 🔧 **프롬프트 커스터마이징**
- 기관별 특수 요구사항이 있다면 "CRITICAL REQUIREMENTS" 섹션에 추가
- 자주 사용하는 문구나 양식이 있다면 템플릿에 반영
- 담당자 정보 형식을 기관 표준에 맞게 수정

### 📊 **품질 관리**
- 생성된 문서는 반드시 사람이 최종 검토
- 민감한 내용의 경우 상급자 승인 후 사용
- 정기적으로 프롬프트 성능 평가 및 개선

### 🚀 **고급 활용법**
- **연속 작업**: 여러 문서를 연속으로 작성할 때 이전 결과를 참조하여 일관성 유지
- **조건부 생성**: "만약 담당자 정보가 없다면..." 등의 조건부 요청 추가
- **스타일 변경**: 격식의 정도나 상세함의 수준을 상황에 맞게 조정
